# Case Estagio BBI

Este repositório apresenta a solução para dois cases do Bradesco BBI, ambos voltados a apoiar análise financeira utilizando Python e LLMs:

- `earnings_call_intelligence_tracker`: transforma transcrições de earnings calls em uma análise estruturada em formato de relatório.
- `macro_scenario_engine`: transforma cenários macroeconômicos em rankings de setores e tickers brasileiros sensíveis ao cenário.
